# Contributing

Install with `uv sync --locked --extra dev`. Run `uv run pytest -q`, `uv run ruff check src tests examples`, and `uv run ruff format --check src tests examples`.

Declare units, signs, observability, sampling assumptions and invalid-data handling. Verify physical changes against analytic identities, independent formulations, statistically justified simulations or measured fixtures. Retain failure cases rather than selecting successful truth peaks.

Detector changes must state their noise law and calibration assumptions. Tracker changes must keep truth outside inference and retain IDs through scoring. A missing observation is distinct from a zero measurement.

Make coherent, substantive commits for models, checks, interfaces, studies or documentation. Do not create empty commits or manufactured dates. Rebuild published evidence from one clean source revision after physical changes.
